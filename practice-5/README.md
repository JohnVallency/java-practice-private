# Практическая работа №5

Вариант 27. Анализ табеля за пять рабочих дней с поддержкой отгулов (`-1`).

Требуется Java 21 или новее.

```bash
mkdir -p out
javac -encoding UTF-8 -d out $(find src -name "*.java")
java -cp out ru.edu.pr02.SelfCheck
```

После unit- и data-driven проверок запускается интерактивный режим. Для выхода введите `exit` или пустую строку.
